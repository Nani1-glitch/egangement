# Pragya & Nithin — Engagement Invitation

A single-page engagement invitation site built with Next.js (App Router).

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
```

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: production build
- `npm run start`: run the production build locally
- `npm run lint`: lint the project
